진도 동기화

진도 · 퀴즈 · 연습문제 초안을 내 GitHub 계정의 비공개 Gist에 저장해 다른 기기에서도 이어서 볼 수 있습니다.

  1. Fine-grained 토큰을 만들고 Account permissions → Gists: Read and write만 켭니다. (클래식 토큰이면 gist 범위만)
  2. 아래에 붙여 넣고 연결합니다. 다른 기기에서도 같은 토큰을 넣으면 기존 Gist를 찾아 이어 받습니다.

토큰은 이 브라우저(localStorage)에만 저장되고 api.github.com으로만 전송됩니다. 공용 기기에서는 쓰지 마세요.
